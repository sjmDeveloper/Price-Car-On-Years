<h1>What This App Is:</h1>
<h3>An application to simulate car prices based on years of use.</h3>
<h1>Inputs:</h1>
<h3>Number of years (n): "This shows the car price from year 1 to year n."</h3>
<h3>Price (new): Original car price.</h3>
<h1>3. How to use it:</h1>
<h5>1. Install CMake if it is not installed.</h5>
<h3>2. Open CMD on Windows or Terminal on Linux, then copy this:</h3>
<h4>cd your_file_path</h4>
<h4>mkdir build</h4>
<h4>cd build</h4>
<h4>cmake ..</h4>
<h4>make</h4>
