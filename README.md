# Car Price Depreciation Simulator

## 1. About the Project
A C++ application that simulates and calculates car price depreciation based on the number of years in use.

## 2. Inputs
* **Original Price (`new`):** The initial price of the brand-new car.
* **Number of Years (`n`):** Displays the estimated car value year by year, from year `1` up to year `n`.

## 3. How to Use It

### Prerequisites
* **CMake** installed on your system.
* A C++ compiler (GCC, Clang, or MSVC).

### Build & Run
Open your terminal (Command Prompt on Windows or Terminal on Linux) and run the following commands:

```bash
cd your_file_path
mkdir build
cd build
cmake ..
make
```
